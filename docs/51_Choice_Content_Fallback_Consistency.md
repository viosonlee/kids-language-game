# 选图干扰项补充与内容加载一致性

> Author / Agent: Codex  
> Date: 2026-10-03  
> Scope: 增量补充 docs/02 第 11 节、23、31、34 的选图与内容校验规则

## 审查发现

技术设计允许在运行时从同 Category 生成 distractor，要求图片不同且候选为 2～4 张。课程规划已有 choiceDistractors，优先使用显式配置，再从同语言、同场景题目补充。然而 AssetContentRepository 在逐题验证时会提前移除没有显式有效干扰项的 choose 模式，导致这部分题目根本无法到达后续规划。只验证 planLesson 的构造数据，不能证明真实加载链可用。

严格构建校验也把空 distractors 一律视为错误，与已实现的同场景补充能力不一致。当前打包的 126 条题目都有显式配置，因此该缺陷主要影响添加新题、choose-only 题目或部分干扰图片不可用时的容错。

## 修改

1. 先按原规则检查必需资源、语言和分类，归一化合法玩法及显式干扰图，并按 ID 去重。
2. 等有效候选条目齐备后，调用相同的 choiceDistractors 判断 choose 是否至少具备一张不同的干扰图。有效显式图片优先，同语言且同场景的有效条目可补充。
3. 没有可用干扰图则移除 choose；若仍有 repeat 就保留，若玩法为空就跳过该题。
4. 严格构建校验允许通过合法同场景条目补充，但继续报告重复、空白、与正确图相同或缺失资源的显式干扰项。完全无可用备选则报告 no playable distractors。校验中的候选也必须先通过资源/语言/分类/合法玩法检查。

这对 docs/23 的“只检查显式干扰项”策略作增量修正，遵循后续课程规划已有规则。未修改题库数据、图片、音频、评分、随机顺序、家长题数或选项数偏好。

## 测试证据

ContentRepositoryTest 新增三项，贯穿 JSON → 真实仓库 → 可用模式/课程规划及严格验证：

- 两个只有 choose 且无显式干扰图的同场景题目能够互为候选并进入练习。
- 显式干扰图缺失时，仅使用资源完整的同场景条目，缺音频的条目不能成为候选。
- 相同图片、其他场景、其他语言、损坏条目及未知玩法均不能保持不可玩的 choose 模式；可用 repeat 保留，choose-only 无备选题移除。

原有内置题库、课程配置和内容完整性测试继续验证三语言 126 条题目及 12 个课程配置。

## 限制

判断的是资源有效、语言/分类匹配及图片不同，不证明图片语义适合儿童理解。docs/47 记录的场景插画语义问题和儿童观察验收仍待完成。本轮无真机/模拟器运行、无公开发布；不把测试通过等同于整体需求完成。
