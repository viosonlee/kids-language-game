## 实现与测试边界

新增 AppDependencies 接口，暴露现有八项应用服务。Android AppContainer 实现接口，AppNavigation 和诊断页改为接受接口；生产服务的初始化、页面导航和练习规则保持原有实现。这样测试可以运行真实导航图、页面、ViewModel、评分器和设置仓库，同时控制题库、识别回调、声音播放与记录写入。

AppNavigationJourneyTest 使用 Robolectric API 29、ComponentActivity 和横屏 1280×800 dp 配置。题库每种语言提供一个可跟读/选图的问候题目，默认一题一轮、手动下一题；自动下一题的两个用例通过真实设置仓库开启该选项。存储使用内存 DataStore 和记录调用收集器，不替代 Room 事务测试。

| 用例 | 实际操作与断言 |
| --- | --- |
| 三语言入口 | 从首页分别选择日语、中文、英语，进入对应语言分类并返回首页 |
| 选图辅助通过与重玩 | 连续三次错误后辅助完成，手动下一题并重玩，正确选图后回首页；四条尝试、两次完成、两个独立题目轮次 |
| 跟读重试与重玩 | 实际评分器处理三次错误文本，先重试后辅助通过；手动完成并重玩，新一轮不残留成功弹层，模型重新加载 |
| 模型恢复与迟到回调 | 模型失败后切换选图，再返回玩法页重试跟读；录音中退出后投递旧识别结果，不生成记录或反馈语音，不恢复旧页面 |
| 家长门禁 | 错误答案不能进入设置；从界面读取当次乘法题，正确作答后进入真实设置页并返回首页 |
| 拒绝麦克风权限 | 点击真实录音按钮取得系统权限请求，通过 Activity 的权限结果桥接返回拒绝；显示恢复入口，选图仍可完成，识别器从未开始录音 |
| 选图自动下一题 | 正确选择后自动进入完成页；回首页再推进时间，不重复跳转或记账，单题表扬和整轮庆祝各播放一次 |
| 跟读自动下一题 | 正确识别结果后自动进入完成页；回首页后无旧流程复活、重复记录或重复语音 |

识别器替身在取消后有意保留旧回调，以检验真实 ViewModel 是否作废迟到结果。声音替身即时完成并记录资源名，不采集或播放真实音频。用例关闭装饰动效，分别推进 Compose 帧时钟和 Android 主线程时钟；录音状态检查等待布局可见，并同时断言识别器已启动，避免把语义变化早于布局的瞬间当作失败。

## 验证结果

新增八项流程测试全部通过。扩展测试时修正了一个断言遗漏：完整一轮包含单题表扬和完成页庆祝两次语音，最终断言分别核查资源类型和次数。曾出现一次录音图标即时可见断言失败，重跑未复现；补充上述有界布局等待后，全量测试通过。权限测试调用 Activity 的系统回调桥接，编译器会提示该方法已弃用；生产页面仍使用 Activity Result API，没有为此新增 suppression。

## 尚不能证明的事项

这些测试验证受控条件下的真实页面连接与业务流程，未覆盖全部题库、全部系统版本、完整权限设置界面、动画淡出时序、旋转/进程重建或真实麦克风。1280×800 dp 的测试配置不等同于平板截图及触控验收，也不证明儿童可以无文字独立完成。

SDK 仍缺 platform-tools，未执行 connectedDebugAndroidTest；构建仪器测试包不等于设备运行。仍需跨存储进程中断、声音响度/反馈时长、图片语义、目标设备性能与生命周期、升级保留数据和儿童观察验收。ASR 超时/识别率优化保持调查范围，手机布局方案尚未选定。本批未安装或发布 APK，总审查继续保留未完成状态。
