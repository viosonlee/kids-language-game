## 录音失败后的恢复

`RepeatProblem` 将权限、空识别、录音失败、模型未就绪和空题库分别表达。空识别提示为“还没听清，点麦克风再说一次吧”，不再把空文本直接解释为硬件没有收到声音。

`RepeatRecoveryDialog` 提供兔子、麦克风/禁用麦克风图标，以及适用的重试、重听、选图、返回场景和家长入口。主要动作目标为 88dp，按钮区域可换行，弹窗内容可滚动。只有当前课程确实有可玩的选图题目时才提供选图；空内容不提供无效的录音和重听动作。图片与图标能否让幼儿自主理解仍需实际观察。

`RepeatScreen` 切换场景/选图前停止当前会话。系统权限管理从儿童恢复弹窗移到通过现有门禁进入的家长页；该页恢复前台时刷新麦克风权限，并在系统设置入口不可用时显示说明。恢复到选图会替换跟读路由，避免返回一个已经停止的错误会话。

`RepeatViewModel` 明确保存模型是否可用；开始/恢复加载时清空该标记，仅在加载成功后允许录音。加载返回失败或抛出普通异常时提供重试；协程取消继续传播。模型失败后可以重听，但不会因为重听结束而开启不可用的识别器。重试加载保留原课程位置，错误不计为发音错误或辅助通过次数。

以上对应 FR-TEXT-001、NFR-REL-002、NFR-UX-001/004/005 和 NFR-REL-003 的部分范围。原生链接错误、系统识别器异常、完整导航和真实权限往返尚未验收。

## 内容与图片

新增 `ContentIntegrity`，供仓库运行时过滤及测试使用：

- 检查必需 ID、有效目标文字、语言、实际存在的分类、音频和图片字段。
- 本地资源使用可移植的相对路径；拒绝绝对路径、反斜杠、路径穿越和空路径段。
- 本地图片只支持 PNG/WebP/JPG/JPEG，避免把已存在的音频等文件接受为图片；继续兼容当前题库中的内联图片符号。
- Android 资源读取检查位图头部尺寸，过滤不能读取尺寸的位图；这不等于对每个文件全部像素的完整解码验证。
- 运行时隔离坏条目和无效干扰项，保留其他可用内容；分类文件读取失败不缓存空题库，后续请求可恢复。
- 严格测试额外检查跨语言全局 ID、分类元数据、重复/不支持的玩法、别名和干扰项。严格检查由 `test` 执行，仅运行 `assembleDebug` 不会自动运行这些测试。

`PracticeIllustration` 在 IO 线程读取本地位图，以 `Image` 展示；跟读题图和选图卡片统一使用它。文件路径不再作为图片文字显示。加载失败会记录日志，未增加网络图片读取。现有 126 条内容仍使用内联符号，没有替换图片/音频资产。

这些修改覆盖 FR-SPEAK-001、FR-DATA-002/004、NFR-REL-001 的已知源码缺口及 docs/02 的图片路径约定。新测试运行通过之前不能标为验证完成；声音是否清晰、场景图片是否易懂也不能由字段校验证明。

## 首次点击与测试

真实 Compose 恢复弹窗测试发现按钮存在但首次点击不执行：`debouncedClickable` 原先将上次点击时间初始化为 0，系统 uptime 小于防抖间隔时会拒绝首次点击。该现象在 Robolectric 初始时钟下稳定暴露；不能据此推断平板平常 uptime 下的所有点击问题都由此造成。

两个 clickable 分支改为使用明确的“尚未点击”标记，首次点击直接接受，之后才比较间隔。判断先检查标记，避免计算哨兵时间差时溢出。

新增 `DebounceClickTest` 覆盖默认/自定义 interactionSource 两个分支的首次点击、连续点击抑制和间隔后点击；使用 `ShadowSystemClock` 推进实际防抖所用时钟，没有通过延迟第一次点击掩盖问题。

`RepeatRecoveryDialogTest` 在 Robolectric API 29 下渲染真实 Compose Dialog/按钮，覆盖权限恢复、模型失败、空内容和本地图片。`src/testDebug` 仅在 Debug 运行；已有 ViewModel/仓库/内容测试分别补模型重试、不可用选图隐藏、字段与引用完整性、分类读取恢复。
