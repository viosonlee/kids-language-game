# 离线提示音回退与平板连接检查

> Author / Agent: Codex  
> Date: 2026-10-03  
> Status: Implemented; device acceptance pending

本方案基于 docs/50 和 docs/53 增量补充提示音回退边界，不改变语音识别模型、阈值或超时策略。

## 修复

预录音频不可用时，原有 setLanguage 调用可能选中系统的网络语音。现在显式选择语言及地区匹配（允许无地区的同语言语音）、无需网络且未标记为未安装的语音，再调用 setVoice 和 speak。优先精确地区匹配，不借用其他地区的发音。

初始化失败、缺少本地语音、设置或合成失败均返回 OfflinePromptUnavailableException，沿用播放中断处理，避免把未发出的提示音当作正常播放结束并自动录音。诊断页展示明确的离线语音不可用信息。过期合成错误不能中断新的播放。正常预录音频路径保持不变。

## 实机与限制

Windows 识别到 HUAWEI MatePad Pro，USB 文件传输及虚拟光驱接口状态正常；用户确认开启 USB 调试后，ADB 设备列表仍为空，未发现 ADB 接口或异常设备。已请求切换调试开关并重新插拔。未清除应用数据，未启用模拟器，未发布 APK。

本地语音判断依赖系统 TTS 引擎提供的元数据，不能替代 OEM 引擎的实际离线验证。本次不代表 ASR 识别率改善或平板 UI 验收通过。真实语音识别、角色细节动画、插画语义及其余验收项继续沿用 docs/53 的未完成状态。
