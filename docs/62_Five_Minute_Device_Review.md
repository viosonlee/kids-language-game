## 设备交接后立即执行

先确认设备序列号、已解锁和当前应用版本。只启动已安装应用，不默认重新安装。若锁屏或需人工确认，立即告知用户一次，不在无人响应时循环安装。

| 时间预算 | 检查 | 应留证据 |
| --- | --- | --- |
| 0:00–0:30 | 打开当前应用，进入诊断页，检查顶部按钮和滚动 | 当前包版本/安装时间、应用截图 |
| 0:30–2:00 | 中文与英文各等待模型就绪，各录一句页面给定短语；一条手动停止、一条自然结束 | 模型就绪、原始识别文本、结束状态、用户发声条件 |

## 需要验证新版时

在用户明确可操作设备的窗口内，使用预备副本与 `adb -s <已核实序列号> install -r <APK绝对路径>` 覆盖安装。保留数据；若签名不匹配不得卸载绕过。若平板系统要求确认，立即让用户处理；一次被拒绝后不自动重复排队。安装成功后记录 Success 与安装时间，再检查对应修复。
