## 发现与处理

原来的 SettingsRepository 直接把 DataStore 数据映射为设置；MainActivity、首页、音效以及练习流程分别收集这条 Flow，读取或字段类型转换异常可能终止调用协程。家长页三个统计 Flow 也直接使用 stateIn，缺少失败状态与重新订阅入口。首页语言保存没有处理普通写入异常。

本方案基于 docs/22、docs/33、docs/36 增量补充，自本次提交起生效，保留原规范。

设置读取现在返回 SettingsSnapshot，数据与本次读取的错误一起传给页面。每个订阅保留它实际读到的最近值；没有成功读取过时，使用临时默认设置，其中反馈音量为零、背景音乐与动效关闭、自动录音仍默认关闭。这些值只用于本次运行，不写回 DataStore，不删除损坏文件或原有偏好。新订阅读取成功也不会替其他仍在等待重试的订阅清除错误标记。

普通读取异常按 1、2、4、8、16、30 秒间隔重试，随后上限为 30 秒；页面的“重试”可立即重新读取，成功保存设置也会唤醒等待中的读取。取消订阅会停止该订阅的等待与重试。数据源主动发出 CancellationException 时，一次性读取也会得到取消，不转换为临时值或停在 first() 等待中；为此明确处理了 flatMapLatest 默认把子流取消视为结束的行为。

首页与家长页显示读取问题及带刷新图标的重试按钮。首页语言写入失败时保留已保存的语言并显示错误；重试再次保存最后请求的语言。请求序号避免较早请求的迟到错误覆盖较新请求的成功状态。音效管理器在首次读到偏好前保持静音。

## 统计与重置边界

家长统计使用 Loading、Ready、Failed 三种状态。三个统计流至少分别返回一次结果后才显示计数；任一读取异常都会显示错误和重试入口，不把失败显示为零题或“暂无记录”。重试仅重新订阅，不清空数据库，也不抹去此前练习写入失败的独立警告。用户明确执行清空并成功后会重新读取统计。

旧版本累计数来自设置存储；它还未加载或当前读取失败时，不参与总数相加，界面明确标注“旧版累计暂不可用”。正常统计仍遵循已有 Room 聚合含义。

本批没有新增数据库事务、schema 迁移或跨存储原子协议。三个统计查询仍独立更新，不能把组合后的显示称为同一个数据库时刻的事务快照。永久存储故障或不可解析文件可能持续显示恢复提示；本批没有自动抹除数据来获得一个成功的空结果。

首轮定向运行发现统计测试清理时序问题，以及源取消被重试组合吞掉而等待不结束的问题。分别在测试中等待协程清理完成、在生产读取链中保留源取消语义后，25 项定向测试通过。随后实际执行 `test assembleDebug assembleDebugAndroidTest lintDebug --offline` 成功；XML 为 Debug 148 项、Release 136 项，均无失败、错误或跳过。lint 为 0 errors、13 warnings、2 information，与上一批类别一致，没有新增 suppression/baseline。

本批故障注入使用受控 DataStore/统计 Flow；UI 测试运行于 Robolectric API 29。它们不证明真实存储损坏恢复、SoundPool 硬件行为或整页平板布局。SDK 尚缺 platform-tools，没有执行设备端测试；仪器测试包构建不等于运行。
