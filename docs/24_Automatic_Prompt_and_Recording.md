# 24. 自动示范与自动录音设置

> Author / Agent: Codex
> Date: 2026-09-28
> Status: Implemented
> Scope: FR-SPEAK-002/003/012、FR-PARENT-002 增量补齐

- 新增持久化 autoPlayPrompt（默认开启）、autoStartRecording（默认关闭），保持升级前的手动录音习惯。
- 跟读和选图进入新题/恢复时尊重自动示范开关；手动喇叭始终可播放。错误后的引导重播仍保留，以满足温和重试流程。
- 跟读自动录音在示范播放完成、400 ms 过渡后启动；若关闭自动示范，则在题目准备好后的过渡结束启动。启动前两次检查权限；未授权时保持手动麦克风入口，不自动弹权限请求。
- 关闭自动录音后只响应手动麦克风；权限授予回调只请求开始，不使用 toggle，避免已经自动启动时被反向停止。
- 页面暂停取消自动录音等待任务；无声/错误后回到手动重试，不自动形成无限录音反馈循环。未改 Vosk 参数、模型或超时处理。
- 每次准备新题/播放示范时重新读取设置，文字显示和自动下一题同步更新。
- 五项新回归测试验证自动示范关闭仍可手动播放、下一题不自动播、录音等待示范、无权限不录、退出取消待启动、无声不循环。
- 背景音乐、模型效果/超时问题、Room 真机测试及最终审查/推送仍需处理。
