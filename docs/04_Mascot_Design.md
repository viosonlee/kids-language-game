# Kids Language Companion 吉祥物设计书

> Version: 1.0 Draft Baseline  
> Character: Bunny Mascot  
> Asset file: `assets/mascot/bunny_mascot_expression_sheet.png`

---

# 1. 设计目标

本角色用于增强儿童模式的陪伴感、引导感与反馈感，降低“做题”味道，提升愿意开口的意愿。

角色不是 IP 独立企划，而是服务于学习体验：

- 让孩子愿意点开 App；
- 让孩子在不知道该干什么时，通过角色姿态理解任务；
- 让孩子在识别失败时不受打击；
- 让答对后的快乐反馈更像“被夸奖”，而不是单纯系统提示。

---

# 2. 角色定义

- 角色类型：拟人化可爱白兔
- 暂定名称：可后续由家长或产品决定（V1 文档中可暂称 **Momo Bunny**）
- 目标年龄感：幼儿/低龄儿童友好
- 性格关键词：温柔、活泼、鼓励型、陪伴感、不过度吵闹

---

# 4. 动作状态集

| 状态名 | 作用 | 说明 |
|---|---|---|
| Idle | 默认待机 | 微笑挥手，欢迎开始 |
| Listen | 播放示范 / 正在听 | 侧耳倾听，耳边提示线 |
| Speak | 提示孩子开口 | 张嘴引导、手势邀请 |
| Great | 答对庆祝 | 跳跃、星星环绕 |
| TryAgain | 鼓励重试 | 可爱沮丧、耳朵下垂、轻微汗滴 |
| Praise | 鼓励继续 | 点赞/眨眼/称赞 |

---

# 5. 使用规则

1. 角色应贯穿首页、练习页和完成反馈页。  
2. 角色在练习页通常占据次主视觉，不压过题目图片和主操作按钮。  
3. 角色反馈时长建议 0.8 ~ 1.5 秒。  
4. `TryAgain` 必须温和，不可显得受伤、哭泣或被责备。  
5. 一次会话中，角色动作与音效应有节制，避免过于吵闹。  

---

# 6. 开发落地建议

- 当前素材为一张表情姿势集合图，用于确认风格与状态定义；
- 实际开发时建议拆分成单独资源文件；
- 优先导出透明背景 WebP；
- 可用 Compose Animation 制作轻量动效，无需复杂骨骼系统；
- 若后续继续扩展，可追加：Clap、Wave、Sleep、Hint、CelebrateBig 等状态。
