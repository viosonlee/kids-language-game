# 18. 会话音频生命周期与诊断页交互修复

> Author / Agent: Codex
> Date: 2026-09-28
> Scope: 对既有设计的增量修复记录

- 练习暂停恢复保留进度；完成事件只消费一次；手动下一题等待反馈音频结束，空题库不再触发完成奖励。
- 音频使用独立播放凭据，旧回调与旧协程取消不能结束新播放；页面暂停取消所属播放。原生语音模型加载、卸载及直接音频识别串行化，取消时释放资源。
- 诊断页等待模型准备，取消过期识别回调；顶部音效按钮独立成行，保持单行且窄屏可横向滚动；播放发音按钮预留空间，避免被词条内容挤压。
- 首页兔子点击取消矩形波纹，改为 1 → 0.96 → 1 的轻微缩放，保留一秒点击间隔与招呼播放。
- 新增/扩展播放凭据、会话恢复、手动下一题与完成事件回归测试。Android 媒体与真实儿童发音效果仍需真机体验验证。
