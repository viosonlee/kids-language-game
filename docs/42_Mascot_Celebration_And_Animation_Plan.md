## 本批实现

Great/Praise 图片加载完成后执行一次 700ms 动效：最大向上 8dp、放大至 1.05 倍，六颗装饰星星向外扩散并淡出。结束恢复原尺寸和位置，不继续请求动画帧。关闭动效立即恢复静止状态，不显示动态星星；其他状态保留原有轻微浮动。

这是完整 PNG 的位移缩放和程序星星效果，尚不是兔子眼睛、嘴巴或四肢的角色动画。原 Great PNG 自带的静态星星和文字仍保留。

## 用户确认的下一步范围

优先让兔子角色眨眼、挥手、开口和庆祝。沿用现有白兔、服装和画风，练习场景图片暂不扩展。

目前 assets/mascot/manifest.json 只描述六张完整静态 PNG，没有眼睛、嘴巴或手臂图层。适合先补充同一构图、同一尺寸和透明背景的动作序列帧；逐帧检查身份、位置和轮廓一致性，避免播放时抖动。待机低频眨眼，问候短挥手，说话期间开合嘴，成功短庆祝；离开页面、结束说话或关闭动效时停止并回到相应静态姿势。嘴部开合不宣称精确音素口型同步。

新素材应另存，保留静态回退。接入前需检查帧尺寸、透明边缘、内存预算及解码复用；接入后验证状态切换、取消、关闭动效、后台停止及真机视觉效果。

当前会话无可调用的内置 image_gen 工具。imagegen 技能允许经用户选择使用 API/CLI 备用方式，需要本机 OPENAI_API_KEY；已询问，尚未执行任何图片生成或付费 API 调用。角色动作本身未完成。
