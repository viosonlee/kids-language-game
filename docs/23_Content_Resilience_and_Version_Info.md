# 23. 题库容错、分类过滤与版本信息

> Author / Agent: Codex
> Date: 2026-09-28
> Status: Implemented
> Scope: FR-DATA-002/003/004、FR-PARENT-004 增量修复

- ContentRepository 对合法 JSON 数组逐条解码。字段类型错误或缺少必填字段只跳过该条，记录资源文件名和索引；整个文件的 JSON 语法损坏仍无法恢复，返回空结果且不缓存读失败。
- 校验题目 ID、语言、文本、音频资源；配置了缺失/空音频的条目跳过；未配置音频仍允许现有 TTS 回退。重复 ID 保留第一条。
- 选图模式要求非空图片及至少两个去重后、不等于正确答案的干扰项；不满足条件时移除该模式，仍保留有效跟读模式。当前题库图片为 emoji；文件图片渲染不在本次修复范围。
- 分类按当前语言/通用分类和实际有效题目过滤，语言专用标题优先；缓存由 Mutex 串行保护，取消继续传播。
- 分类页面显示加载状态，无可用内容时给出返回提示；切换语言不保留上种语言的分类。
- 新增 content/manifest.json（schemaVersion 1、contentVersion 1.0.0、三语言文件和题数），家长页面读取应用包版本、内容版本与 models/manifest.json 模型版本。
- ContentRepositoryTest 覆盖坏条目隔离、资源缺失、语言不符、重复选项、分类切换、临时读取失败、取消、真实内置题库。真实题库仍为 62/32/32 题，均保留两种模式和四个分类。
- 完整自动设置、背景音乐、数据库设备验证、ASR 优化决策和发布检查仍未结束；本文件不表示总目标完成。
