# Kids Language Companion 产品需求规格书（PRD / SRS）

> Version: 1.1 Draft Baseline  
> Status: Development-ready draft  
> Primary Platform: Android 10 tablet / 10.8-inch / 2560×1600 / 16:10  
> Product Type: Preschool listening & speaking trainer

---

# 1. 背景

目标儿童目前生活在日本，处于幼儿园环境，但日语理解和口语能力不足，无法稳定理解老师与同学的日常表达。

同时，儿童尚不能依赖文字阅读来完成普通语言学习 App 的课程，因此传统以文字、拼写、菜单、选择题说明为中心的学习流程不适合。

儿童对类似 Duolingo 中“听到或看到目标表达 → 开口模仿 → 系统马上判定 → 获得动画和声音奖励”的短反馈循环表现出较高兴趣。

因此需要一个更窄、更适合学龄前儿童的学习工具：

- 不依赖识字；
- 优先训练“听懂”和“敢开口”；
- 每个任务很短；
- 成功后立即给予正反馈；
- 不因发音不标准频繁打击儿童；
- 可以在 Android 平板上独立运行；
- 日语优先，同时支持中文和英语；
- 核心功能在无网络环境下仍可使用。

# 2. 产品目标

## 2.1 核心目标

**G-001** 帮助儿童建立日常高频表达的“声音 → 场景含义”关联。

**G-002** 通过低压力模仿练习提高主动开口频率。

**G-003** 优先提高日本幼儿园中的基础生存沟通能力。

**G-004** 为中文和英语提供同一套低识字门槛的长期启蒙方式。

**G-005** 让儿童能够在很少或没有成人持续操作的情况下完成短时练习。

## 2.2 次要目标

- 为家长提供简单的练习进度和偏好控制。
- 允许未来按场景持续添加内容而不修改 App 业务逻辑。
- 为未来替换 ASR 引擎、增加新语言、增加对话练习预留接口。

**G-006** 通过固定卡通吉祥物增强儿童黏性、降低练习焦虑，并用统一角色承载鼓励式反馈。

---

# 3. 非目标

V1 明确不追求以下能力：

**NG-001** 不做完整 Duolingo 类课程树。

**NG-002** 不做拼写、键盘输入、汉字认读、假名认读等文字学习主流程。

**NG-003** 不做严格的语言考试评分。

**NG-004** 不输出“72 分”“发音不合格”之类容易引起挫败的儿童成绩。

**NG-005** 不做开放式 AI 聊天机器人。

**NG-006** 不做社交、排行榜、好友、社区。

**NG-007** 不做商城、虚拟货币、付费抽奖或高刺激游戏化系统。

**NG-008** V1 不要求云账号、家长账号或跨设备同步。

**NG-009** V1 不要求服务端内容管理系统。

# 4. 目标用户

## 4.1 Primary User：幼儿

特征：

- 幼儿园阶段；具体年龄不作为硬编码条件。
- 不能稳定阅读日语、中文或英语句子。
- 可以通过图片、声音、简单图标理解操作。
- 注意力持续时间短。
- 需要高频、即时、明确的正反馈。
- 发音可能不标准，儿童语音特征与成人明显不同。
- 对复杂菜单、长说明、文字错误提示不敏感或无法理解。

## 4.2 Secondary User：家长

需求：

- 选择语言和场景。
- 控制是否显示文字。
- 设置练习长度、自动下一题、音量等。
- 查看简单进度。
- 必要时重置进度。
- 查看应用诊断信息。

# 6. 产品原则


## 6.1 Mascot-driven Emotional Design

- 主流程中应存在一个固定吉祥物角色，承担“欢迎、示范、倾听、祝贺、鼓励重试”的情感反馈职责。
- 吉祥物在儿童模式中属于核心 UI 元素，不是装饰性素材。
- 吉祥物必须在成功反馈时提供高辨识度正向动作；在失败或未识别时提供温和鼓励动作，不制造压力。
- 吉祥物在 V1 应至少覆盖以下状态：`Idle`、`Listen`、`Speak`、`Great`、`TryAgain`、`Praise`。
- 儿童模式中，吉祥物口头鼓励语音可作为后续增强项；V1 可先使用 UI 动画 + 短音效。


## P-001 No Reading Required

儿童必须可以在完全不阅读文字的情况下完成主要学习流程。

## P-002 One Task, One Action

一个画面尽量只要求一种主要行为：听、说、点选其中之一。

## P-003 Immediate Positive Feedback

成功后在 200 ms 级别尽快启动可感知反馈，不等待复杂后台流程。

## P-004 Forgiving Recognition

语音判断必须宽松，特别是启蒙阶段。

## P-005 No Dead End

任何语音题都不能因为识别错误让儿童永久卡住。

## P-006 Audio First

学习内容以声音和图像为第一信息载体，文字为辅助信息。

## P-007 Offline First

核心学习必须在断网情况下可运行。

## P-008 Calm Gamification

鼓励使用星星、角色动作、短音效等正反馈，但避免老虎机式高刺激、倒计时压力和惩罚性连续登录机制。

# 7. V1 产品范围

V1 只实现两种核心模式。

## 7.1 Mode A — Listen & Repeat

流程：

```text
显示场景图片
→ 播放标准语音
→ 提示儿童开口
→ 自动或手动开始录音
→ 检测儿童说话结束
→ 本地 ASR
→ 宽松判定
→ 正反馈 / 温和重试
→ 自动下一题
```

目标：建立“听音 → 模仿开口”能力。

## 7.2 Mode B — Listen & Choose

流程：

```text
播放一句日常表达
→ 显示 2～4 张图片
→ 儿童点击正确图片
→ 正反馈 / 轻提示
→ 自动下一题
```

目标：建立“听音 → 理解含义”能力。

# 9. 功能需求

## 9.1 应用启动与基础导航

### FR-APP-001

应用必须可以在 Android 10 上启动并进入 Child Home。

**Acceptance:** 冷启动不需要登录、联网或接受非必要条款。

### FR-APP-002

核心功能必须在飞行模式下可使用。

### FR-APP-003

Child Mode 应默认以横屏显示。

### FR-APP-004

应用应记住上次选择的语言和主要偏好。

---

## 9.2 语言选择

### FR-LANG-001

必须支持：

- Japanese (`ja-JP`)
- Chinese (`zh-CN`)
- English (`en-US`)

### FR-LANG-002

儿童选择语言时不得要求阅读文字。

语言入口应使用旗帜/场景图/示范语音等组合。

### FR-LANG-003

切换语言后，下一次练习必须使用对应内容、标准音频和 ASR 模型。

### FR-LANG-004

同一时间只允许一个语言 ASR 模型处于活动状态。

---

## 9.3 Category / Lesson

### FR-CONTENT-001

内容必须按照语言与场景分类。

### FR-CONTENT-002

Child Mode 的分类入口必须以图片为主要识别方式。

### FR-CONTENT-003

每个 Lesson 应支持配置：

- Item 顺序
- 随机或固定顺序
- 本轮题数
- 练习模式

### FR-CONTENT-004

新增 Item 原则上不得修改 Kotlin 业务代码。

# 10. Listen & Repeat 功能需求

### FR-SPEAK-001

每题必须至少包含：

- target text
- target language
- prompt audio
- illustration
- accepted form / alternatives

### FR-SPEAK-002

进入题目后应自动播放一次标准语音，除非家长设置关闭自动播放。

### FR-SPEAK-003

儿童可以点击大尺寸 Speaker 按钮重复播放示范语音。

### FR-SPEAK-004

应用必须能够录制麦克风输入并进行本地语音识别。

### FR-SPEAK-005

应用必须将识别结果与当前 Item 的目标表达进行宽松比较。

### FR-SPEAK-006

正常通过时必须给予视觉 + 声音正反馈。

### FR-SPEAK-007

一次未通过不得出现红色叉、扣分或负面成绩。

建议反馈：

- “再听一次”
- 角色做“再来一次”的动作
- 自动重播目标音频

### FR-SPEAK-008

同一题连续失败不得无限循环。

默认规则：

- Attempt 1：正常阈值
- Attempt 2：正常阈值或轻微放宽
- Attempt 3：允许 Soft Pass
- Soft Pass 后进入下一题

具体阈值由技术设计定义。

### FR-SPEAK-009

Soft Pass 在儿童界面不得显示为失败。

### FR-SPEAK-010

儿童没有说话时，系统应提示“可以说啦”，而不是判定发音错误。

### FR-SPEAK-011

儿童在说话过程中不得因为超短静音间隙立即停止录音。

### FR-SPEAK-012

家长应可关闭自动录音，改为按大按钮开始/结束录音。

# 11. Listen & Choose 功能需求

### FR-LISTEN-001

每题播放一句目标语音，并显示 2～4 个候选图片。

### FR-LISTEN-002

正确答案的位置必须可随机化，避免形成固定位置记忆。

### FR-LISTEN-003

点选正确图片后应立即给出正反馈并自动进入下一题。

### FR-LISTEN-004

点错后不得立即给出惩罚性反馈。

推荐：

- 轻微摇动错误卡片；
- 再播一次音频；
- 正确目标可在第二次错误后轻微高亮。

### FR-LISTEN-005

连续多次选择错误后应提供辅助，而不是永久卡题。

# 12. 正反馈系统

### FR-FEEDBACK-001

至少支持：

- 星星 / 闪光动画
- 角色开心动作
- 成功音效

### FR-FEEDBACK-002

成功反馈持续时间应短，默认约 0.8～1.5 秒，然后自动进入下一题。

### FR-FEEDBACK-003

反馈必须可以在 Parent Mode 中关闭声音。

### FR-FEEDBACK-004

不得使用高频闪烁或可能诱发不适的视觉效果。

### FR-FEEDBACK-005

V1 不使用失去生命、扣星、连续签到中断等惩罚机制。

### FR-PARENT-001

Child Mode 应提供不容易被儿童误触进入的 Parent Mode 入口。

家长模式至少允许设置：

- 默认语言
- 文字显示

- 自动录音
- 自动下一题
- 单轮题数
- 背景音乐 / 音效开关

### FR-PARENT-003

- 最近使用时间

### FR-PARENT-004

家长模式应显示 App Version、Content Version、ASR Model Version。

# 20. 关键用户流程

## UC-001 第一次进入日语练习

```text
启动 App
→ 看到三种语言入口
→ 点击日本语场景按钮
→ 点击“幼儿园”图片
→ App 播放第一句
→ 儿童跟说
→ App 给出星星动画
→ 自动进入下一题
```

**成功条件：** 全流程儿童无需阅读文字。

## UC-002 听不懂老师指令练习

```text
进入“老师说什么”
→ 播放「すわって」
→ 出现 3 张动作图片
→ 儿童点“坐下”
→ 正反馈
```

## UC-003 ASR 连续识别失败

```text
儿童认真尝试
→ Attempt 1 未达到阈值
→ 温和提示并重播
→ Attempt 2 仍失败
→ 再次鼓励
→ Attempt 3 仍失败
→ Soft Pass
→ 正向结束并进入下一题
```

**关键：** 不出现“你说错了 3 次”的儿童文案。

# 21. 验收标准

## 21.1 功能验收

- [ ] 三种语言均可进入。
- [ ] 两种练习模式均可独立运行。
- [ ] 无网络时可以完成整轮练习。
- [ ] 预录标准语音可重复播放。
- [ ] 麦克风授权后可录音和识别。
- [ ] 拒绝麦克风权限后 App 不崩溃。
- [ ] ASR 失败后不会卡死。
- [ ] Soft Pass 逻辑生效。
- [ ] 进度在 App 重启后保留。
- [ ] 家长模式设置重启后保留。
- [ ] 内容缺图或缺音频时不会导致整个 App 崩溃。

## 21.2 UX 验收

- [ ] 不看文字可以完成 Child Mode 主流程。
- [ ] 主要按钮不存在过小点击区域。
- [ ] 2560×1600 横屏无元素遮挡或超出安全区域。
- [ ] 成功反馈不遮挡下一题的关键音频。
- [ ] 错误反馈不使用强烈红叉 / 失败音效。
- [ ] Child Mode 没有复杂设置入口或系统术语。

## 21.3 实际儿童观察验收

至少进行一轮真实观察，不要求儿童理解测试目标。

观察重点：

- 是否知道什么时候该说话；
- 是否会主动重复点击 Speaker；
- 是否理解成功反馈；
- 识别失败时是否表现出明显困惑或挫败；
- 是否能独立进入下一题；
- 3～5 分钟后是否仍愿意继续；
- 哪类图片最容易理解。

不得只用成人开发者语音完成最终验收。

# 22. 产品成功指标

V1 不追求商业 KPI，重点验证产品是否真正帮助儿童使用。

建议本地统计以下指标：

| 指标 | 目的 |
|---|---|
| Session completion rate | 是否经常中途放弃 |
| Repeat-audio count | 哪些表达难理解 |
| Normal pass rate | ASR 与内容整体匹配情况 |
| Assisted pass rate | False Negative / 难度线索 |
| Average attempts per Item | 哪些 Item 需要调整 |
| Listen & Choose error count | 听力或图片语义是否不清 |
| Voluntary repeat sessions | 儿童是否愿意再次打开 |

这些数据默认只保存在本机。

# 附加功能需求：卡通角色（Mascot）

**FR-MAS-001** 系统应在儿童模式首页、练习页和反馈页展示统一主吉祥物角色。  
**FR-MAS-002** 系统应至少支持 6 个吉祥物状态：Idle、Listen、Speak、Great、TryAgain、Praise。  
**FR-MAS-003** 跟读练习开始录音前应显示 `Speak` 或 `Listen` 相关状态，帮助儿童理解当前任务。  
**FR-MAS-004** 正确或通过时应显示 `Great` 或 `Praise` 状态，并伴随轻量粒子/星星效果与积极音效。  
**FR-MAS-005** 未通过时应显示 `TryAgain` 状态，不得使用恐吓、嘲讽、强惩罚式表现。  
**FR-MAS-006** 家长模式可提供“降低动画强度/关闭角色音效”的开关，但默认开启。  

# 角色验收要求

- 角色设计在不同状态下必须保持同一身份特征（配色、服装、比例、面部特征保持一致）。
- 在 2560×1600 目标平板上，角色在主要反馈页中应清晰可见，不得因过小而失去表情信息。
- 同一角色资源不得出现明显风格漂移或比例失真。
- 儿童模式主流程中，角色反馈不应遮挡题面关键图片区或录音按钮。
