本记录增量补充 docs/53、61。用户要求“进行非受阻的项目”，据此实施已调查的两项识别代码修复。docs/65 延期的兔子动画不在本次范围内。

## 超时结果回收

核对实际依赖 vosk-android 0.3.47 的 RecognizerThread 字节码：到达时限时只发送 onTimeout，非超时分支才调用 getFinalResult。原引擎直接返回空文本并关闭识别器，丢弃尚未形成 endpoint 的最终文本。

新路径先保存当前回调、使旧回调失效，再停止并回收录音线程，在关闭识别器前读取 finalResult。非空文本正常进入评分；空文本仍保留 Timeout 状态，不制造识别结果。线程无法停止时不读取或关闭仍可能使用中的识别器；读取异常返回失败并清理资源。模型、录音时限和评分阈值保持不变。

回归覆盖最终文本仅交付一次、取消中同步旧回调、新会话不被旧超时影响、停止失败不读取解码器、解码异常仍释放资源、空结果行为。

## 日文读音匹配

增加 Kuromoji IPADIC 0.9.0 离线词典，将整句分词读音转换为统一假名，仅新增完整读音相等的通过路径。例如順番/じゅんばん、眠い/ねむい、一緒に遊ぼう/いっしょにあそぼう。未知词保留原文，不删除未知片段；该路径保留长音及词序。没有为回放数据手工追加题目别名，也没有放宽原有模糊评分阈值。

这是词典读音比较，不是音素识别；多音词依赖词典和上下文分词，不能保证任意日文表达都能正确归一化。已有宽松匹配规则仍保留，读音不相等不意味着最终一定 Retry。

日文跟读评分与诊断评分使用后台调度，避免词典首次初始化占用 UI 线程。结果返回前校验会话代次；退出或开始新会话后旧评分不得触发反馈。测试覆盖在异步评分期间退出页面。

合并依赖中的 META-INF Markdown 文档，保留许可证、NOTICE 与贡献者信息。词典随 APK 分发，运行时不联网。Debug APK 从预备包 242796568 字节增加到 256871174 字节，增加约 14.1 MB；词典常驻内存与首次加载的真机指标仍待测。
