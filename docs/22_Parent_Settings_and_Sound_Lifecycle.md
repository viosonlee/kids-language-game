# 22. 家长设置、权限与短音效生命周期补充

> Author / Agent: Codex
> Date: 2026-09-28
> Status: Implemented; physical-device verification pending
> Scope: FR-PARENT-002/003、技术设计第 13/14 节的增量修复

- 家长页增加默认语言选择、音效开关和 0–100% 音量；现有 selectedLanguage 持久化并用于首页。音效音量与设备媒体音量分别控制提示音效和示范发音。
- SoundPool 按设置乘以各音效相对增益，并更新正在播放的音效音量；静音时停止音效。最多保留四条 stream，停止与释放幂等，release 取消设置收集任务。
- 跟读录音前、跟读/选图离开时、诊断页退出/录音前及 Activity 后台时停止短音效，避免残留音效污染录音或在后台继续响。
- SettingsRepository 防御历史非法音量和题数；新增清空进度保留设置、非法值与音量持久化回归测试。
- 删除 MainActivity 首屏权限弹窗，保留跟读麦克风操作时按需申请；拒绝权限不阻断选图。
- 家长统计增加最近练习时间（事件 MAX 时间），空记录显示暂无。自动下一题说明改为等待反馈语音结束，移除不准确的固定 1.2 秒描述。
- Room 仪器测试依赖已下载，assembleDebugAndroidTest 成功；实际设备测试待执行，ADB 当前没有连接设备。
- 自动示范播放、自动录音、背景音乐/版本展示和其他审查项尚未完成；语音识别优化按用户要求仍处于调查阶段。
